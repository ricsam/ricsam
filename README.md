# Richie

Software engineer working on TypeScript tools and web applications.

## Selected projects

- [`agentic-web-research`](https://github.com/ricsam/agentic-web-research) — self-hosted, model-directed web research with SearXNG, Playwright, Markdown extraction, and SSE.
- [`isolate`](https://github.com/ricsam/isolate) — V8 sandbox host for scripts, app servers, tests, browser sessions, and nested runtimes with explicit capability bindings.
- [`shell-dsl`](https://github.com/ricsam/shell-dsl) — in-process POSIX-style shell with registered commands, streaming pipelines, scripts, and virtual filesystems.
- [`richie-router`](https://github.com/ricsam/richie-router) — file-based React router that generates separate client and server-safe route manifests.
- [`richie-rpc`](https://github.com/ricsam/richie-rpc) — Zod contracts for Bun servers, typed clients, OpenAPI, React Query, streams, SSE, and WebSockets.
- [`formula-engine`](https://github.com/ricsam/formula-engine) — spreadsheet parser and evaluator with sparse storage, dependency tracking, caching, autofill, and snapshots.
- [`selection-manager`](https://github.com/ricsam/selection-manager) — spreadsheet selection, navigation, editing, fill, merged-cell, and clipboard state.
- [`react-tanstack-table-ui`](https://github.com/ricsam/react-tanstack-table-ui) — virtualized TanStack Table UI with separate Material UI, Tailwind, and Bleu skins.
- [`enstore`](https://github.com/ricsam/enstore) — authenticated network file server with CLI and Node `fs`-style client packages.
- [`enschedule`](https://github.com/ricsam/enschedule) — PostgreSQL scheduler with Bun workers, typed job schemas, access control, logs, and a React dashboard.
- [`nafs`](https://github.com/ricsam/nafs) — Node-style filesystem API over memory, local files, S3, and Enstore.

Also: [`sequence-viewer`](https://github.com/anocca-ab/sequence-viewer), [`richie-cron`](https://github.com/ricsam/richie-cron), [`jsonc-cli`](https://github.com/ricsam/jsonc-cli), and [`react-mixitup`](https://github.com/ricsam/react-mixitup).
